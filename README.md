GTA 6 Cover Art app — turns a photo and a caption into GTA 6-style cover art: multi-panel posters with a Vice City neon-sunset grade, exported as PNG, for make.fun gta6-cover-art-01.

## What it does

Upload a photo, pick a layout (grid, hero, full-bleed, nine-panel, tilt, magazine, diptych) and a grade (sunset, neon vice, golden hour, noir, palm teal, rose gold, midnight), edit the caption, and export the cover as a PNG in 1080x1080, 1080x1350, 1920x1080 or Story 1080x1920. Everything runs offline in the browser.

## Run it

```sh
node serve.ts   # serves app/ on :8080
```
